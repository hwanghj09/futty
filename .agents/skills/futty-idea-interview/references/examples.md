# Futty Idea Interview — 사용 예제

## 1. 짧은 FPS 요청 → 심화

**사용자**: FPS 게임 만들어줘.

**AI**: 어떤 전투 경험을 상상하나요?
1. A 영웅 능력·팀 조합 / B 정밀 사격·라운드 전술 / C 고속 PvE / D 생존·탈출 / E 직접 설명
2. A 팀워크 / B 1:1 승부 / C 성장 / D 다른 재미
3. 게임 첫 장면이 어떻게 보이나요?

**사용자**: 1-B, 2-B. 폐학교에서 서로 싸워.

**AI**: 정밀 사격 중심, 폐학교 맵까지 확인했어요.
1. A 현실적인 어둠 / B 밝은 만화 / C 초현실적 폐학교?
2. A 적 팀 전멸 / B 목표물 설치/해제 / C 정보 확보 후 탈출?
3. 사망 후 A 관전 / B 리스폰 / C 팀원 부활?
4. 학교 안에서 꼭 일어났으면 하는 장면은?

→ 다음 답을 보고 스킬/맵/사운드/대전 인원/첫 MVP를 추가 질문. 사용자가 답하지 않은 부분은 결정하지 않는다.

## 2. 질문을 많이 해 달라는 경우

**사용자**: 기획 함께 해줘. 많이 물어봐.

**AI**: 첫 라운드 3~4개 질문 → 답변의 분기점을 뽑아 두 번째 라운드 3~4개 → 플레이 루프, 세계관, 아트, 멀티, 차별화, 범위 등으로 여러 라운드 이어간다. 매 턴 이미 답한 내용을 요약하고 새 항목만 묻는다.

## 3. 충분히 상세한 즉시 구현 요청

**사용자**: 3D 싱글 FPS, 45초 움직이는 드론 사격장, WASD·마우스·R 재장전, 점수 HUD, Windows. 지금 만들어.

**AI**: 비전이 충분하므로 긴 인터뷰 생략. 미정 디자인을 가정으로 기록하고 제작 스킬로 진행.

## 4. 중간에 인터뷰 중지

**사용자**: 이 정도면 됐어. 나머지 알아서 해.

**AI**: 확정·미정·가정을 구분해 기획 브리프를 만들고 즉시 다음 단계로 전달.

## 5. 게임 브리프 출력

~~~text

확정된 기획: [핵심 플레이/승패/시점/모드/스타일]

처음 5~15분: [장면 → 행동 → 피드백 → 목표]
MVP 필수: [...]
후속 개발: [...]
원치 않는 것: [...]
AI 제안/미정: [...]
~~~
